# complexity-vs-binary

Interactive figure for a BSF research proposal.

**Two axes of complexity: dimensionality and resolution.** Each social pole is a
square judgment of the same situation. *Dimensionality* subdivides the square into
independent cells (one cell is uni-dimensional; a k×k grid gives k² dimensions);
*resolution* grades each cell from binary (black/white) to continuous (gray). The
two poles sit at the ends of a distance scale — the gap between them is their
polarization — and raising either axis of representational complexity pulls them
together. A distance-metric selector (percentage, Manhattan, Euclidean, RMS, MSE)
shows how much the effect depends on normalizing for dimensionality.

**Live figure:** https://yohayzvi.github.io/complexity-vs-binary/

Single self-contained `index.html` — no build step or dependencies.
